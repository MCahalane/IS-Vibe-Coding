# Vibe Coding: Building with AI

A standalone Information Systems learning module: how business students can use AI to create, test and share a simple web application, safely and responsibly. Part of the [Information Systems Plug & Play Learning Modules](https://mcahalane.github.io/IS-Learning-Modules/).

- 8 parts (about 3–3½ hours), searchable glossary, worked prompts with copy buttons, six diagrams, a case study link and ungraded quick checks (49 questions plus a 6-item agent quiz).
- Five short audio overviews in `audio/`.
- No build step, no tracking, no accounts. Open `index.html` or serve the folder.

## Files

- `index.html`: the whole module (inline CSS and JavaScript). The UNSW theme is the `<style id="unsw-theme">` block at the end of `<head>`.
- `assets/`: images, logos and screenshots.
- `audio/`: audio overviews (intro, Parts 1, 2, 3 and 8).
- `favicon.svg`, `.nojekyll`.

## Origin

Adapted from a course-specific study companion. Course labels, assessment guidance, team-project material, lecture slides and links that required a university login were removed so the module stands alone. Third-party images are credited in their captions.

## Publishing

Settings → Pages → Deploy from a branch → `main` / `(root)`.
